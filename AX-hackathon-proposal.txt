1. AI로 해결하고자 하는 문제 상황 또는 새롭게 시도해보고 싶은 업무/서비스는 무엇인가요?

현재의 업무를 더 효율적으로 바꾸는 것부터, 지금까지 없던 새로운 업무 경험이나 서비스를 만드는 것까지 자유롭게 적어주세요.

제안하는 서비스는 WorkMemory AI — 업무를 패턴화해 효율화 솔루션을 제안하는 AI 업무 비서다. PC에서 평소처럼 일하면 사용자가 허용한 업무 데이터가 자동으로 쌓이고, AI가 업무 성격에 맞게 정리해 개선 방법과 필요한 문서 초안을 제공하는 경험을 만들고자 한다.

PC 업무에서는 파일 사이의 값 복사, 시스템 조회, 문서 입력과 서식 맞춤 같은 작은 수작업이 반복된다. 여러 프로그램에 흩어진 행동을 개별 작업으로만 기억하면 어떤 절차가 반복되는지, 어느 단계를 자동화하면 좋을지 찾기 어렵다. 프로그램 사용 시간이나 입력 횟수만으로도 업무의 목적과 개선 방법을 설명하기 어렵다.

업무를 돌아보거나 일일·주간·월간 보고를 작성할 때에는 흩어진 자료를 다시 모아야 한다. 짧은 자료 확인·검토·동료 지원·문제 해결 과정은 기억에서 빠지기 쉽고, 별도로 기록하는 데도 시간이 든다.

WorkMemory AI는 일상 업무 데이터의 자동 축적 → 업무 성격에 따른 자동 분류·패턴화 → 업무 효율화 솔루션 제안으로 반복 수작업의 개선을 돕는다. 같은 기록으로 자신의 업무를 회고하고 필요한 문서를 자동 작성할 수 있게 한다. 처음에 수집할 프로그램과 파일·대화·사이트 조건을 정하면 그 범위 안에서 기록이 쌓이도록 설계한다. 타임테이블과 프로그램 사용 현황은 자신의 일하는 방식을 이해하는 부수 기능으로 제공한다.

2. 제안한 아이디어를 실현하기 위해 AI를 어떻게 활용할 계획인가요?

AI 활용 방안과 이를 통해 문제를 해결하거나 새로운 변화를 만드는 방법을 구체적으로 작성해 주세요.

① 자동으로 쌓인 데이터를 업무 성격에 맞게 분류

사용자가 허용한 작업의 시각·조작 종류·프로그램·문서·페이지·입력 또는 클릭 대상 등 최소 맥락을 로컬에 수집한다. AI는 설정한 주기에 맞춰 관련 기록을 연결하고 자료 작성·분석·개발·검토·협업 등 업무 성격에 따라 자동 분류하도록 할 계획이다. 연속 키 입력 원문과 화면 전체는 기본 수집 대상에서 제외한다.

다음은 기밀 없는 시연 자료를 이용한 가상의 예시다.

관측된 기록: Excel의 ‘프로젝트 A’ 자료에서 범위 선택·복사
AI가 연결·분류할 업무: 프로젝트 A 자료 취합 / 자료 정리

관측된 기록: 허용한 업무 사이트에서 관련 정보를 조회
AI가 연결·분류할 업무: 프로젝트 A 정보 확인 / 조사·검토

관측된 기록: 문서 편집기에서 관련 내용을 입력하고 표 정리
AI가 연결·분류할 업무: 앞선 기록과 연결된 프로젝트 A 자료 작성 / 문서 작성

같은 프로젝트 이름이라도 자료 작성과 개발 오류 수정처럼 목적이 다른 업무는 구분한다. 여러 클릭을 곧바로 여러 업무로 세지 않고, 연결 이유와 근거를 업무 카드에 표시한다. 사용자는 모호한 이름·분류나 잘못된 연결만 짧게 수정하고, 수정 내용은 이후 분석에 반영한다.

② 반복 흐름을 패턴화해 효율화 솔루션 제안·제공

AI가 누적된 업무의 목적·처리 순서·데이터 이동을 비교해 반복 흐름을 패턴화한다. 무엇을 반복했는지에 더해, 어느 단계를 어떻게 바꾸면 좋을지 자동화 설계안이나 템플릿으로 제공하고자 한다.

패턴화한 업무 흐름: 여러 Excel 파일의 값을 취합하고 같은 형식으로 정리
효율화 솔루션: 공통 양식과 자동 취합 설계안
제공할 적용 방법: 필요한 열·파일 조건, 통합·중복 확인·서식 적용 단계

패턴화한 업무 흐름: 업무 사이트의 정보를 문서에 반복 입력
효율화 솔루션: 입력 항목 대응표와 문서 자동 채움 템플릿
제공할 적용 방법: 조회 항목, 문서에 넣을 위치, 사람이 확인할 예외

패턴화한 업무 흐름: 비슷한 자료 검토·확인을 반복
효율화 솔루션: 체크리스트와 규칙 기반 자동 점검 설계안
제공할 적용 방법: 반복 확인 항목, 자동 점검 조건, 수동 판단 단계

솔루션에는 대상 업무·반복 근거·개선 단계·적용 조건을 담고, 사용자가 채택·수정·보류할 수 있게 한다. 미확인 패턴은 후보로 표시하며, 실제 업무 반복 횟수는 사용자가 확인한 업무 단위로 계산한다. 자동화 실행은 후속 확장으로 두고, 절감 시간과 효과는 실제 적용 후 검증한다.

③ 같은 기록으로 업무 회고와 문서 자동화

AI가 업무 기록을 기간·프로젝트·업무 유형별로 정리하고, 사용자가 선택한 서식에 맞춰 문서 초안을 생성하도록 할 계획이다.

활용: 업무 회고
AI가 제공할 결과: 수행 업무·반복 흐름·개선 시도와 관련 근거
사용자 활용: 무엇을 했고 어떤 과정을 개선할지 돌아보기

활용: 일일·주간·월간 보고
AI가 제공할 결과: 수행 업무·진행 내용·이슈·다음 계획의 서식별 초안
사용자 활용: 필요한 내용만 보완해 문서 작성 시간 절감

활용: 기타 업무 문서
AI가 제공할 결과: 확인한 업무 사례·결과·기여의 요약
사용자 활용: 필요시 평가노트 등 다른 문서에 재사용

문서 항목에는 업무 카드와 관측 근거를 연결한다. 완료 여부·실제 결과·기여는 사용자 확인이나 추가 자료가 있을 때 포함하고, 부족한 정보는 보완 항목으로 남긴다. 사용자가 검토한 뒤 저장·내보낼 수 있게 한다.

④ 부수 기능: 타임테이블과 프로그램 사용 현황

수집 시각·앱 전환·업무 분류를 활용해 시간대별 타임테이블, 업무별 소요 시간 추정치, 프로그램별 관측 사용 시간과 사용 비중을 제공할 수 있다. 어떤 업무에 시간이 많이 들고 어떤 도구를 자주 오가는지 확인하는 참고 자료로 활용한다.

허용한 범위에서 관측한 시간만 집계하고, 업무별 배분은 근거가 있을 때만 추정한다. 겹치는 구간은 중복 합산하지 않으며 유휴·오프라인 업무·미수집·미분류 구간을 구분한다. 일부 프로그램만 수집했다면 그 범위의 통계임을 표시한다.

구현에는 운영체제 이벤트·접근성 API와 필요한 앱 연동, 로컬 DB, 업무 카드 화면과 LLM API를 활용할 계획이다. 건수·날짜·관측 시간은 코드로 계산하고, AI는 맥락에 따른 업무 연결·분류·패턴 해석·솔루션과 문서 초안 생성을 맡는다.

아이디어가 구현되면 사용자가 무엇을 하고, AI가 어떤 결과를 보여줄지 적어주세요.

2일 동안 선택적 수집 → 업무 자동 분류·패턴화 → 효율화 솔루션 제안 → 업무 회고·일일 보고 초안 생성을 연결하는 프로토타입을 구현하고자 한다.

주요기능: 허용 범위 설정·자동 기록
사용자가 하는 일: 프로그램과 지원 가능한 파일명·사이트 조건을 지정하고 평소처럼 작업
AI·시스템이 보여주는 결과: 허용한 작업만 로컬에 축적하고 수집 상태 표시. 시작·중지·전체 삭제 제공

주요기능: 업무 자동 분류·확인
사용자가 하는 일: 여러 프로그램을 오가며 일하고 모호한 항목만 수정
AI·시스템이 보여주는 결과: 관련 기록을 업무 카드로 연결하고 분류·연결 근거 표시

주요기능: 반복 업무 패턴화·솔루션 제안
사용자가 하는 일: 자료 취합·문서 정리를 반복하고 제안을 검토
AI·시스템이 보여주는 결과: 반복 근거와 개선 단계·조건을 담은 솔루션 한 개, 자동화 설계안 또는 템플릿

주요기능: 업무 회고·일일 보고
사용자가 하는 일: 기간을 선택해 업무를 돌아보고 결과·이슈를 보완
AI·시스템이 보여주는 결과: 업무 목록과 근거가 연결된 일일 보고 초안. 수정·저장·텍스트 내보내기

주요기능: 부수 기능의 선택 시연
사용자가 하는 일: 시간대별 흐름과 프로그램 사용 현황 확인
AI·시스템이 보여주는 결과: 관측한 범위의 타임테이블·프로그램 집계와 미수집 구간 표시

대표 시연은 두 개 이상의 프로그램에서 ‘스프레드시트 자료 취합 → 업무 사이트 확인 → 문서 정리’를 수행하는 흐름으로 구성한다. 1일 차에는 허용 조건 판별·수집·로컬 저장과 AI 자동 분류를 연결하고, 2일 차에는 반복 패턴·솔루션 한 개와 일일 보고 초안·근거 연결·내보내기를 구현할 계획이다.

허용·비허용 파일과 사이트를 섞어 제외한 개인 작업이 저장·전송되지 않는지도 확인한다. 실제 수집한 날짜·프로그램·범위를 표시하고, 여러 날의 누적 모습은 별도의 가상 자료로 설명한다.

타임테이블·프로그램 집계는 여유가 있을 때 시연한다. 메신저 대화 상대 등 추가 세부 필터, 주간·월간 보고·다양한 서식·정기 문서 생성, 고급 편집과 여러 앱·운영체제 지원은 후속 확장으로 둔다. 앱별 조건을 판별할 수 없으면 해당 작업은 수집하지 않는다.

4. 이 아이디어의 주요 사용자는 누구이며, 어떤 기대효과가 있나요?

고객 가치 창출, 오류 감소, 정보 접근성 개선, 업무 효율 향상 등 기대하는 변화를 구체적으로 적어주세요.

주요 사용자는 PC로 일하는 SDS 임직원이다. 기획·개발·분석·운영·지원 등 직무와 사용하는 도구가 달라도, 반복 수작업을 줄이고 자신의 업무를 돌아보려는 필요에 대응한다. 보고서 작성 여부와 관계없이 활용할 수 있으며, 장기적으로 다양한 조직의 PC 업무로 확장하고자 한다.

사용자의 상황: 자료 이동·입력·서식 맞춤 반복
기대하는 변화: 반복 패턴을 근거로 효율화 솔루션과 적용 방법 제공
확인 방법: 제안의 실행 가능성 검토, 적용 후 시간·수작업 변화 확인

사용자의 상황: 여러 앱에 업무 맥락이 흩어짐
기대하는 변화: 업무 성격에 맞게 연결·분류하고 놓친 일을 떠올릴 단서 제공
확인 방법: 사용자 기준 업무와 비교해 잘못된 연결·누락·수정 부담 확인

사용자의 상황: 자신의 업무 흐름을 돌아보기 어려움
기대하는 변화: 기간·프로젝트별 기록과 개선 시도를 회고

최초 수집 설정과 일상적인 검토·수정 부담을 함께 측정한다. 솔루션 제안의 유용성과 실제 적용 효과는 구분하고, 장기적인 시간 절감과 오류 감소는 후속 사용을 통해 검증한다. 조직에는 사용자가 선택해 공유한 업무 요약과 개선 제안으로 표준화·자동화 우선순위 논의를 도울 수 있다.

오프라인 업무나 미지원 앱의 작업은 필요시 사용자가 추가할 수 있게 한다. 관측한 활동 시간·입력 횟수·유휴 시간을 전체 근무시간이나 개인 생산성 점수로 환산하지 않는다.

5. 아이디어가 구현된 모습을 한 줄로 요약하면 어떤 모습일까요?

개인정보 보호를 위한 선택적 데이터 수집

기본값은 수집하지 않는 상태로 두고, 사용자가 선택한 프로그램과 세부 조건에 맞는 작업만 추적하도록 설계한다. 프로그램 전체를 허용하거나, 같은 프로그램 안에서도 업무용 파일·대화·사이트로 범위를 좁힐 수 있게 한다.

선택 단위: 프로그램
사용자가 설정할 수 있는 예시: 업무용 Excel과 문서 편집기만 선택
수집 제한 방식: 선택하지 않은 앱의 활동·입력 내용 제외

선택 단위: 파일명·업무 키워드
사용자가 설정할 수 있는 예시: Excel 파일명에 ‘프로젝트 A’ 또는 ‘월간집계’가 포함된 경우만 허용
수집 제한 방식: 같은 Excel에서도 조건 밖의 개인 파일 제외

선택 단위: 메신저 대화 상대·대화방
사용자가 설정할 수 있는 예시: 지정한 업무 상대 또는 프로젝트 대화방만 허용
수집 제한 방식: 식별 가능한 지원 앱의 해당 대화만 대상. 다른 대화·전체 대화 내역 제외

선택 단위: 브라우저 사이트
사용자가 설정할 수 있는 예시: Chrome에서 지정한 업무 도메인·경로만 허용
수집 제한 방식: 조건 밖의 개인 사이트·탭 제외. 전체 방문 기록·URL 쿼리는 기본 제외

허용 여부는 로컬에서 최소 식별 정보로 먼저 판단하고, 프로그램과 설정한 세부 조건을 함께 만족한 작업만 상세 맥락을 읽고 저장한다. 제외 조건을 우선하고, 조건을 판별할 수 없으면 수집하지 않는다. 앱·파일·대화·탭이 전환될 때 다시 확인하며, 판단에 잠시 사용한 비허용 식별 정보도 기록하거나 외부로 보내지 않는다. 앱별 세부 식별의 지원 범위는 구현 과정에서 검증해 표시한다.

비밀번호·인증정보 입력은 제외하고, 연속 키 입력 원문·전체 화면·클립보드 원문·문서와 대화의 전체 내용은 기본 수집하지 않는다. 기록 시작·일시중지·현재 수집 상태 확인·전체 삭제를 제공한다. 원문은 로컬에 우선 저장하며 운영체제 보호 기능을 활용한다.

수집 허용과 외부 AI 전송 허용은 별도로 설정한다. 외부 모델에는 허용 자료 중 필요한 최소 맥락만 전송하고 민감정보 가림 처리와 전송 자료 미리보기를 제공할 계획이다. 자동 분석도 사용자가 정한 범위에서만 실행한다. 삭제는 원본과 분석 입력 사본·업무 카드·솔루션·문서 초안·시간 집계에 함께 적용한다. 개인 원본을 조직에 자동 공유하지 않고, 사용자가 선택한 요약과 제안만 공유할 수 있도록 한다.

장기적으로는 솔루션 적용 전후 비교, 직무별 템플릿과 지원 환경을 확장하고자 한다. 반복 업무의 발견이 효율화 솔루션으로 이어지고, 같은 기록이 업무 회고와 문서 초안에 활용되는 경험을 핵심 가치로 둔다.
