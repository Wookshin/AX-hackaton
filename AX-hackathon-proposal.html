01

문제와 주요 사용자

AI로 해결하고자 하는 문제 상황 또는 새롭게 시도해보고 싶은 업무/서비스는 무엇인가요?

현재의 업무를 더 효율적으로 바꾸는 것부터, 지금까지 없던 새로운 업무 경험이나 서비스를 만드는 것까지 자유롭게 적어주세요.

제안하는 서비스는 WorkMemory AI입니다. 사용자가 PC에서 평소처럼 일하면 허용한 범위의 업무 데이터가 자동으로 쌓이고, AI가 여러 프로그램의 작업을 업무 성격에 맞게 연결합니다. 이를 ‘프로젝트 A 자료 취합’, ‘개발 오류 수정’처럼 업무별 수행 내역으로 정리해 먼저 보여주는 AI 업무 비서입니다.

여러 프로그램을 오가며 일하다 보면 하루 동안 어떤 업무를 했는지 한 번에 파악하기 어렵습니다. 짧은 자료 확인·검토·동료 지원·문제 해결 과정은 기억에서 빠지기 쉽고, 업무를 돌아보거나 보고할 때 흩어진 자료를 다시 모아야 합니다. 별도의 업무 기록을 빠짐없이 작성하는 데도 시간이 듭니다.

수행 내역이 쌓이면 개별 작업만 볼 때는 알아차리기 어려웠던 반복 과정도 확인할 수 있습니다. 예를 들어 여러 Excel 파일의 값을 취합하고 문서의 서식을 맞추는 일을 여러 차례 수행했다면, 비슷한 목적과 순서가 반복되는 공통 흐름으로 묶습니다. 이러한 정리를 업무 패턴화라고 하며, 반복 흐름이 확인되면 자동 취합이나 공통 양식 적용처럼 수작업을 줄일 업무 효율화 솔루션, 즉 구체적인 개선 방법을 제안합니다.

정리된 업무 기록은 자신이 어떤 일을 했는지 돌아보는 회고에도 활용합니다. 같은 기록을 근거로 일일·주간·월간 보고와 필요한 업무 문서의 초안을 작성하고, 사용자가 실제 결과나 기여 등 부족한 내용만 보완할 수 있게 합니다. 처음에 수집할 프로그램과 파일·대화·사이트 조건을 정하면 그 범위 안에서만 기록이 쌓이도록 설계합니다. 부수적으로 업무별 시간과 프로그램 사용 현황도 제공해 자신의 일하는 방식을 돌아보도록 돕습니다.

02

AI 활용 계획

제안한 아이디어를 실현하기 위해 AI를 어떻게 활용할 계획인가요?

AI 활용 방안과 이를 통해 문제를 해결하거나 새로운 변화를 만드는 방법을 구체적으로 작성해 주세요.

① 데이터를 자동으로 모으고 업무별 수행 내역을 먼저 정리합니다

사용자가 허용한 작업의 시각·조작 종류·프로그램·문서·페이지·입력 또는 클릭 대상 등 필요한 정보를 사용자 PC에 수집합니다. AI는 설정한 주기에 맞춰 관련 기록을 연결하고, 자료 작성·분석·개발·검토·협업 등 업무 성격에 따라 분류합니다. 그 결과를 업무명·수행 내용·관련 프로그램이 포함된 목록으로 먼저 보여줍니다. 연속 키 입력 원문과 화면 전체는 기본 수집 대상에서 제외합니다.

다음은 기밀 없는 시연 자료를 이용한 가상의 예시입니다.

수집된 기록 AI가 정리해 보여주는 수행 내역
Excel의 ‘프로젝트 A’ 자료에서 범위 선택·복사 프로젝트 A 자료 취합 / 자료 정리
허용한 업무 사이트에서 관련 정보를 조회 프로젝트 A 정보 확인 / 조사·검토
문서 편집기에서 관련 내용을 입력하고 표 정리 앞선 기록과 연결된 프로젝트 A 자료 작성 / 문서 작성

업무 하나의 이름·수행 내용·관련 기록을 함께 확인하는 요약 화면을 업무 카드로 제공합니다. 같은 프로젝트 이름이라도 자료 작성과 개발 오류 수정처럼 목적이 다른 업무는 구분합니다. 사용자는 연결이 불확실한 항목이나 잘못된 이름·분류만 짧게 수정하고, 수정 내용은 이후 분석에 반영합니다. 여러 클릭이나 입력 수정이 곧바로 여러 건의 업무가 되지 않도록 정리합니다.

② 누적된 기록에서 반복 흐름이 확인되면 개선 방법을 제안합니다

업무별 수행 내역이 쌓이면 AI가 목적·처리 순서·자료 이동을 비교해 반복되는 흐름을 패턴화합니다. 이를 바탕으로 어떤 단계를 줄이거나 자동화하면 좋을지 효율화 솔루션을 제안합니다.

개선 방법은 처리 단계·필요한 입력·확인 조건을 정리한 자동화 설계안이나, 반복해서 사용할 수 있는 공통 양식인 템플릿으로 제공합니다. 다음은 반복 업무와 연결한 개선 예시입니다.

패턴화한 업무 흐름 제안할 효율화 솔루션 제공할 적용 방법
여러 Excel 파일의 값을 취합하고 같은 형식으로 정리 공통 양식과 자동 취합 설계안 필요한 열·파일 조건, 통합·중복 확인·서식 적용 단계
업무 사이트의 정보를 문서에 반복 입력 조회 항목을 문서의 어느 위치에 넣을지 정한 대응표와 자동 채움 템플릿 조회 항목, 문서 입력 위치, 사람이 확인할 예외
비슷한 자료 검토·확인을 반복 검토 체크리스트와 정해진 조건에 따른 자동 점검 설계안 반복 확인 항목, 자동 점검 조건, 수동 판단 단계

제안에는 대상 업무·반복 근거·개선 단계·적용 조건을 담고, 사용자가 채택·수정·보류할 수 있게 합니다. 반복으로 묶은 이유가 불확실하면 확인이 필요한 후보로 표시하며, 실제 반복 횟수는 사용자가 확인한 업무 단위로 계산합니다. 해커톤에서는 설계안 또는 템플릿 한 개를 제안하고, 자동화 실행은 후속 확장으로 둡니다. 절감 시간과 효과는 실제 적용 후 검증합니다.

③ 같은 업무 기록을 회고와 문서 작성의 근거로 활용합니다

문서 작성에는 ①에서 정리한 업무별 수행 내역을 기본 자료로 활용합니다. 사용자가 기간·프로젝트·업무 유형별로 자신의 일을 돌아보고, 선택한 서식에 맞는 문서 초안을 생성할 수 있게 합니다. 개선 제안을 검토하거나 적용했다면 해당 내용도 관련 기록과 함께 반영합니다.

활용 AI가 제공할 결과 사용자 활용
업무 회고 기간별 수행 내역·반복 흐름·개선 시도와 관련 기록 어떤 일을 했고 다음에 무엇을 개선할지 돌아보기
일일·주간·월간 보고 확인된 수행 내역과 사용자가 보완한 진행 내용·이슈·다음 계획을 담은 초안 필요한 내용을 검토·보완해 보고 문서 작성
평가 노트 등 필요한 문서 수행한 업무 사례·사용자가 확인한 결과와 기여·관련 근거를 연결한 초안 같은 업무 기록을 문서 작성의 근거로 재사용

문서 항목에는 해당 업무 카드와 수집 기록을 연결합니다. 실제 완료 여부·결과·기여·다음 계획은 관련 자료가 있거나 사용자가 확인·추가한 경우에 포함합니다. 기록만으로 알 수 없는 내용은 보완 항목으로 남기고, 사용자가 검토한 뒤 저장·내보낼 수 있게 합니다.

④ 부수 기능으로 타임테이블과 프로그램 사용 현황을 제공합니다

수집 시각·프로그램 전환·업무 분류를 활용해 시간대별로 어떤 업무를 했는지 보여주는 표인 타임테이블을 제공합니다. 업무별 소요 시간 추정치와 프로그램별 사용 시간·비중도 함께 확인할 수 있습니다. 어떤 업무에 시간이 많이 들고 어떤 도구를 자주 오가는지 돌아보는 참고 자료로 활용합니다.

허용한 범위에서 확인한 시간만 집계하고, 업무별 시간은 연결 근거가 충분할 때만 추정합니다. 겹치는 구간은 중복 합산하지 않으며, 입력이 없는 시간·PC 밖의 업무·수집하지 않은 구간·분류가 불확실한 시간을 구분합니다. 일부 프로그램만 수집했다면 해당 범위의 통계임을 표시합니다.

구현에는 PC 조작과 프로그램 전환 정보를 수집하는 기능, 사용자 PC의 저장소, 업무 카드 화면과 AI 모델 연동 기능을 활용할 계획입니다. 건수·날짜·확인된 활동 시간은 코드로 계산하고, AI는 작업의 맥락에 따른 업무 연결·분류·반복 흐름 해석·개선 제안·문서 초안 생성을 맡습니다.

03

2일 구현 기능

해커톤 2일 동안 구현해 보고 싶은 주요기능은 무엇인가요?

아이디어가 구현되면 사용자가 무엇을 하고, AI가 어떤 결과를 보여줄지 적어주세요.

2일 동안 선택한 범위의 자동 수집 → 업무별 수행 내역 정리·조회를 먼저 구현합니다. 정리된 기록이 누적되면 반복 흐름의 패턴화와 개선 제안을 연결합니다. 업무 회고와 일일 보고 초안은 수행 내역이 정리된 시점부터 활용할 수 있도록 구현합니다.

주요기능 사용자가 하는 일 AI·시스템이 보여주는 결과
허용 범위 설정·자동 기록 프로그램과 지원 가능한 파일명·사이트 조건을 지정하고 평소처럼 작업 허용한 작업만 사용자 PC에 축적하고 수집 상태 표시. 시작·중지·전체 삭제 제공
업무별 수행 내역 조회·수정 어떤 일을 했는지 목록으로 확인하고 불확실한 항목만 수정 관련 기록을 업무 카드로 연결하고 업무명·수행 내용·분류·연결 근거 표시
반복 업무 확인·개선 제안 누적된 자료 취합·문서 정리 내역에서 반복 흐름과 제안을 검토 반복 근거와 개선 단계·조건을 담은 솔루션 한 개, 자동화 설계안 또는 템플릿
업무 회고·일일 보고 기간을 선택해 업무를 돌아보고 실제 결과·이슈·다음 계획을 보완 같은 수행 내역을 근거로 일일 보고 초안 생성. 수정·저장·텍스트 내보내기
부수 기능의 선택 시연 시간대별 흐름과 프로그램 사용 현황 확인 수집한 범위의 타임테이블·프로그램 집계와 미수집 구간 표시

초안 검토에서는 자신의 업무를 새롭게 발견하는 경험과 간단한 사용자 확인, 구체적인 시연 사례가 필요하다는 의견이 나왔습니다. 이후 사용자 피드백을 반영해 평소처럼 일하며 쌓인 데이터로 어떤 업무를 했는지 먼저 보여주는 경험을 첫 가치로 정리했습니다. 업무 기록이 누적되면 비슷한 목적과 처리 순서의 반복을 찾아 묶는 업무 패턴화를 수행하고, 확인된 반복 흐름을 줄이거나 자동화할 구체적인 개선 방법을 제안합니다. 이러한 개선 방법을 업무 효율화 솔루션으로 설명합니다. 정리된 기록은 자신의 업무를 돌아보는 회고와 필요한 문서 작성에도 활용합니다.

해커톤에서는 허용한 기록의 수집·자동 분류를 연결해 업무별 수행 내역 목록을 먼저 구현합니다. 누적된 반복 작업 한 가지에는 자동화할 단계·입출력 조건을 정리한 설계안이나 공통 양식인 템플릿을 제안합니다. 같은 업무 기록으로 일일 보고 초안 한 종류를 작성하며, 문서 생성은 반복 흐름 발견을 기다리는 기능으로 두지 않습니다. 실제 결과·기여·다음 계획은 관련 근거가 있거나 사용자가 확인·보완한 경우에 포함합니다. 주간·월간 보고와 필요시 평가 노트 등 다양한 문서 서식은 확장 항목입니다. 대상은 PC로 일하는 SDS 임직원이며, 시연은 대표 프로그램 조합으로 구체화합니다. 타임테이블과 프로그램 집계는 관측한 범위에서 제공하고 수집 허용 조건은 저장 전에 적용합니다.

핵심 메시지는 **“평소처럼 일하면 AI가 업무별 수행 내역을 정리해 보여주고, 누적 기록에서 확인된 반복 흐름을 패턴화해 효율화 솔루션을 제안하며 같은 기록으로 업무 회고와 문서 자동화를 돕는 AI 업무 비서입니다.”**로 정리했습니다.

P2 업무별 시간과 프로그램 사용 현황 활용이 드러나지 않음 부수 기능으로 타임테이블·관측 사용 시간·업무별 추정치를 추가하고 부분 수집·중복·유휴·미수집 구간 처리 명시
P2 반복 개선의 조직적 활용 경로가 약함 사용자가 선택한 요약으로 반복 수작업의 표준화·자동화 우선순위를 설명하는 경로 추가
P2 계획된 시연이 실제 기억 누락·시간 절감의 증거처럼 보일 여지 기능·복원 품질 시연과 별도의 사용자 효과 검증 구분, 일상 확인·수정 시간과 최초 설정 비용 측정

관측과 해석의 구분, 원본 근거, 사용자 수정 보존, 완료·성과의 과장 방지는 설계 원칙으로 유지했습니다. 데이터 항목에는 수집·전송 설정과 부수 시간 집계를 추가했습니다. 수집 허용과 외부 AI 전송 허용을 분리하고, 개인 원본의 자동 조직 공유를 하지 않는 설계도 명시했습니다.

초안 검토 당시에는 수정본을 심사기준·기술 검증 에이전트가 다시 읽고 핵심 가치와 범위의 개선을 확인했습니다. 이번 사용자 피드백에서는 문체를 존댓말로 통일하고, ‘자동 축적 → 업무별 수행 내역 표시 → 누적 기록의 반복 흐름이 확인되면 개선 제안’의 설명 순서를 맞춥니다. 같은 기록은 정리된 시점부터 회고와 문서 작성에 활용할 수 있도록 설명합니다. 본문·설계 메모·README와 출력용 HTML·Word·TXT에서도 이러한 흐름을 일치시키고, 타임테이블과 추가 앱 필터·다양한 문서 서식의 우선순위를 유지합니다.

아직 해결됐다고 볼 수 없는 핵심 질문

  1. 수집할 기록에 수행 내역을 정리할 정보가 충분합니까? 키보드·마우스 조작에 앱·문서·조작 대상의 맥락을 결합하고, 프로그램 간 연결과 분류를 검증합니다. 앱별 관측 범위와 부족한 맥락도 표시할 계획입니다.
  2. 확인하는 수고보다 얻는 편익이 큽니까? 카드 수, 잘못된 연결·누락, 수정 횟수와 검토 총시간을 측정합니다. 선택 묶음 확인이 잘못된 후보를 그대로 받아들이게 하지 않는지도 봅니다.
  3. 업무 목록의 유용성과 반복 흐름 발견을 구분해 확인합니까? 먼저 수행 내역 목록이 업무 파악에 도움이 되는지 확인하고, 누적 기록에서 새로 발견한 반복 흐름도 별도로 묻습니다. 시연용 가상 3건이나 계획된 작업을 실제 기억 누락 감소의 실측으로 제시하지 않습니다.
  4. 장기 누적에서도 근거를 유지합니까? 핵심 기능을 검증하는 최소 구현 제품에서는 실제 분석 범위를 표시합니다. 장기 확장 전 전체 기간 조회, 업무 분류·수정 보존과 같은 업무의 중복 집계를 검증합니다.
  5. 조직의 개선에 실제로 쓰입니까? 선택해 공유한 요약이 개선 대상을 고르는 데 유용한지 확인합니다. 채택·실행·실제 효과는 서로 다른 단계로 추적합니다.
  6. 개인 작업이 수집·전송 전에 차단됩니까? 같은 앱에서 허용·비허용 파일·탭·대화를 교차 사용하고 저장 자료·오류 로그·모델 입력을 대조합니다. 조건 판별 실패와 제외 우선 동작도 확인합니다. 앱별로 검증한 지원 범위만 표시합니다.
  7. 타임테이블이 실제 관측 범위에 맞게 해석됩니까? 부분 수집의 사용 비중, 중복·유휴·미수집 구간 처리를 검증합니다. 관측 시간을 전체 근무시간이나 개인 생산성 점수로 제시하지 않습니다.

발표 구성

첫 장면은 **‘여러 프로그램에서 한 일이 업무별로 정리되어 오늘 무엇을 했는지 한눈에 확인되는 모습’**으로 구성합니다. 먼저 수집 허용 범위를 설정하고 평소처럼 작업한 기록이 업무명·수행 내용·관련 근거를 담은 목록으로 정리되는 과정을 보여줍니다. 필요한 경우 잘못된 이름·분류·연결을 짧게 수정합니다.

이후 기록이 누적된 상황에서 자료 취합·서식 정리처럼 비슷한 목적과 순서가 반복되는 흐름을 보여줍니다. 이 반복을 패턴화한 근거를 설명하고, 해당 단계를 줄이거나 자동화할 방법을 설계안·템플릿으로 제안합니다.

같은 수행 내역으로 업무를 회고하고 일일 보고 초안을 생성·수정·내보내는 장면을 마무리에 둡니다. 문서 작성은 정리된 기록에서 바로 가능한 기능으로 설명하며, 실제 결과·기여·다음 계획은 관련 근거와 사용자의 보완 내용을 반영합니다. 짧은 실제 반복 작업과 별도의 가상 장기 자료를 구분합니다. 타임테이블·프로그램 집계는 구현 여유가 있을 때 보여주고, 메신저 세부 필터·주간·월간 보고·다양한 서식·정기 문서 생성과 자동화 실행은 후속 확장으로 설명합니다.
