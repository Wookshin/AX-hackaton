01

문제와 주요 사용자

AI로 해결하고자 하는 문제 상황 또는 새롭게 시도해보고 싶은 업무/서비스는 무엇인가요?

“평소처럼 일한 기록이 쌓여, 어떤 업무를 개선할 수 있는지까지 알려주면 좋겠다.”

주요 대상 사용자는 PC로 업무를 수행하는 SDS 임직원이다. 자료 취합·분석·개발·문서 작성·시스템 운영 등 다양한 업무에서 여러 프로그램을 오가며 일한다. 파일 사이의 값 복사, 시스템 조회, 같은 형식으로 정리하기처럼 작은 수작업이 반복되어도, 바쁜 일상에서는 그 흐름을 파악하고 개선 방법까지 찾기 어렵다. 프로그램별 사용 시간이나 입력 횟수만으로는 업무의 목적과 자동화 가능성을 설명하기도 어렵다.

업무를 돌아보거나 보고서를 작성할 때에도 별도의 기록 부담이 생긴다. 짧은 자료 확인, 검토, 동료 지원과 문제 해결 과정은 기억에서 빠지기 쉽고, 일일·주간·월간 보고 때마다 흩어진 자료를 다시 모아야 한다. 업무를 수행하면서 자연스럽게 남는 데이터를 활용하면 개선 대상을 찾는 일과 업무 기록·문서 작성을 함께 도울 수 있다.

WorkMemory AI는 일상 업무 데이터의 자동 축적 → 업무 성격에 따른 자동 분류·패턴화 → 효율화 솔루션 제안을 중심 흐름으로 제안한다. 반복되는 절차와 수작업을 찾아 표준 양식, 자동 취합, 입력·검증 절차 자동화 등 실행 방법이 담긴 개선 솔루션을 제공하고자 한다. 축적된 업무 기록은 회고와 문서 자동화에도 재사용한다. 업무별 타임테이블과 프로그램 사용 현황은 자신의 일하는 방식을 이해하는 부수 기능으로 제공한다.

처음에 사용자가 수집할 프로그램과 파일·대화·사이트 조건을 선택하면, 그 범위 안에서 데이터가 자동으로 축적되도록 설계한다. 해커톤에서는 대표 프로그램 조합에서 선택적 수집·저장, 업무 분류·패턴화, 효율화 솔루션 한 개와 보고 초안 한 종류까지 이어지는 프로토타입을 개발할 계획이다. 사용자는 모호한 업무나 잘못 연결된 항목만 짧게 수정할 수 있게 한다.

02

AI 활용 계획

제안한 아이디어를 실현하기 위해 AI를 어떻게 활용할 계획인가요?

① 일상 업무 데이터를 자동 축적하고 업무 성격에 맞게 분류

사용자가 허용한 프로그램과 작업에서 조작 시각·종류, 사용 중인 앱과 문서·페이지, 입력·클릭 대상 등 필요한 맥락을 수집할 계획이다. 초기 설정 이후에는 평소처럼 일하면 기록이 쌓이고, 설정한 주기에 맞춰 AI가 관련 기록을 업무 후보로 연결하고 분류하도록 한다. 연속 키 입력 원문과 화면 전체는 기본 수집 대상에서 제외한다.

다음은 기능을 설명하기 위한 가상의 기록이다.

관측된 기록 AI가 제안하는 업무 후보·분류
허용한 Excel의 ‘프로젝트 A’ 자료에서 범위 선택·복사 프로젝트 A 자료 취합 / 자료 정리
허용한 업무 사이트에서 ‘프로젝트 A’ 관련 정보를 조회 앞선 자료와 관련된 정보 확인 / 조사·검토
문서 편집기에서 ‘프로젝트 A’ 내용을 입력하고 표를 정리 여러 도구의 작업이 이어진 프로젝트 A 자료 작성 / 문서 작성

AI는 시간적 흐름과 업무 목적을 함께 해석해 여러 프로그램에 걸친 작업을 연결한다. 예를 들어 Excel의 자료 취합과 문서의 표 정리를 하나의 자료 작성 업무로 묶되, 같은 프로젝트 이름이 등장해도 개발 오류 수정은 다른 성격의 업무로 구분한다. 자료 작성·분석·개발·검토·협업 등의 분류를 제안하고, 사용자가 이름과 분류를 수정하면 이후 분석에 반영한다.

기본 화면은 하루의 업무 카드 목록으로 구성한다. 사용자는 필요한 항목만 확인·수정하고, 연결 근거는 원할 때 펼쳐 본다. 개별 클릭이나 입력 수정마다 별도 업무 기록을 작성하도록 요구하지 않는다. 프로그램 사용 시간이나 공통 단어만으로 묶은 결과와 비교해 AI가 업무 의미를 잘 복원하는지도 검증할 계획이다.

② 누적 데이터를 패턴화하고 업무 효율화 솔루션을 제안·제공

AI가 누적된 업무에서 비슷한 목적·처리 순서·데이터 이동을 찾아 반복 흐름으로 패턴화할 계획이다. 어떤 일을 반복했는지와 함께, 어느 단계를 어떻게 바꾸면 좋을지 제안한다. 다음은 가상 기록을 바탕으로 한 솔루션 예시다.

패턴화한 업무 흐름 제안·제공할 효율화 솔루션 함께 보여줄 내용
여러 Excel 파일의 값을 모으고 같은 형식으로 정리 공통 양식과 자동 취합 처리 흐름 제공 필요한 열·입력 파일 조건, 통합·중복 확인·서식 적용 단계
업무 사이트의 정보를 확인해 문서에 반복 입력 입력 항목 대응표와 문서 자동 채움 템플릿 제안 조회할 항목, 문서에 넣을 위치, 사람이 확인할 예외
비슷한 자료 검토와 확인 절차를 반복 검토 체크리스트와 규칙 기반 자동 점검 설계안 제공 반복 확인 항목, 자동 점검 조건, 수동 판단이 필요한 단계

솔루션 카드에는 대상 업무, 반복 근거, 개선할 단계, 적용 방법과 필요한 조건을 담는다. 해커톤에서는 실제 짧은 반복 작업 한 가지에 대해 자동화 설계안 또는 템플릿 한 개를 제시하고, 사용자가 채택·수정·보류할 수 있도록 구현할 계획이다. 여러 날의 누적 패턴은 별도의 가상 자료로 설명한다.

관측 이벤트의 반복과 실제 업무의 반복을 구분한다. 반복 횟수는 사용자가 확인한 업무 단위로 집계하고, 미확인 묶음은 후보로 표시한다. 자동화 실행 기능은 후속 확장으로 두며, 실제 절감 시간과 개선 효과는 사용자가 솔루션을 적용한 뒤 검증한다.

③ 같은 기록으로 나의 업무를 회고하고 필요한 문서를 자동 작성

업무 기록을 기간·프로젝트·업무 유형별로 정리해 어떤 일을 했고 어떤 흐름이 반복되었는지 돌아볼 수 있게 한다. 사용자가 선택한 기간과 서식에 맞춰 같은 기록을 문서 초안으로 변환하고, 실제 결과·이슈·기여 등 부족한 정보만 보완하도록 할 계획이다.

활용 정리할 내용 사용자에게 제공하는 가치
업무 회고 기간별 수행 업무, 반복 흐름, 개선 시도와 확인할 항목 기억에 의존하지 않고 자신의 업무를 돌아보고 다음 개선 방향 검토
일일·주간·월간 보고 자동화 수행 업무·진행 내용·이슈·다음 계획을 선택 서식에 맞춘 초안 흩어진 기록을 다시 모으는 부담과 반복 문서 작성 시간 감소
필요시 다른 업무 문서에 활용 사용자가 확인한 업무 사례·결과·기여와 관련 근거 평가노트 등 필요한 문서에 같은 기록을 선택적으로 재사용

해커톤에서는 업무 기록 조회와 일일 보고 초안 한 종류의 생성·수정·저장·텍스트 내보내기를 핵심 결과물로 구현할 계획이다. 주간·월간 보고와 다양한 문서 서식, 정기 자동 생성은 확장 항목으로 둔다. 문서 항목마다 관련 업무 카드와 관측 근거를 연결하고, 완료 여부·실제 결과·기여는 사용자 확인이나 추가 자료가 있을 때 포함한다. 부족한 정보는 보완 항목으로 남긴다.

④ 부수 기능: 업무 타임테이블과 프로그램 사용 현황

수집한 시각·앱 전환·업무 분류 정보를 활용해 시간대별 업무 타임테이블, 업무별 소요 시간 추정치, 프로그램별 관측 사용 시간과 사용 비중을 제공할 수 있다. 사용자는 어떤 업무에 시간이 많이 들었는지, 어떤 프로그램을 자주 오갔는지 확인하고 효율화 솔루션을 검토할 참고 자료로 활용한다.

시간은 허용한 범위에서 관측한 활동 구간을 기준으로 집계한다. 업무별 배분은 연결 근거가 충분할 때만 추정하고, 겹치는 구간은 중복 합산하지 않는다. 유휴·오프라인 업무·미수집 구간과 분류가 불확실한 시간은 구분해 표시한다. 일부 프로그램만 수집했다면 그 범위의 사용 비중임을 명시하며, 이를 전체 근무시간이나 개인 생산성 점수로 해석하지 않는다. 해커톤에서는 여유가 있을 때 간단한 타임라인과 프로그램별 집계를 시연하고, 정교한 시간 배분은 후속 검증 대상으로 둔다.

전체 처리 흐름은 허용 범위의 데이터 자동 축적 → AI 업무 분류·패턴화 → 효율화 솔루션 제안 + 업무 회고·문서 자동화로 설계한다. 건수·날짜·관측 시간은 코드로 계산하고, AI는 맥락에 따른 업무 연결·분류·패턴 해석·솔루션과 문서 초안 생성을 담당한다. 키보드·마우스 이벤트, 접근성 API와 필요한 앱 연동으로 최소 맥락을 확보하고, 로컬 DB·업무 카드 화면·LLM API를 연결할 계획이다. 수집 조건 적용과 민감정보 제외를 저장·외부 전송보다 먼저 수행한다.

03

2일 개발 계획

해커톤 2일 동안 구현해 보고 싶은 주요 기능은 무엇인가요?

2일 동안 선택적 데이터 수집 → 업무 자동 분류·패턴화 → 효율화 솔루션 제안 → 업무 회고·보고 초안 생성으로 이어지는 프로토타입을 개발하고자 한다. 대표 시나리오는 ‘스프레드시트 자료 취합 → 업무 사이트 정보 확인 → 문서 정리’처럼 여러 프로그램을 오가는 업무로 잡는다. 수집 가능성을 확인한 두 개 이상의 프로그램에서 짧은 작업을 시연하고, 앱별 관측 범위를 표시할 계획이다.

우선순위 구현 항목 완료 기준
필수 허용 범위 설정과 데이터 수집·저장 선택한 프로그램과 지원 가능한 파일명·사이트 조건을 적용하고, 비허용 작업은 저장하지 않음. 시작·중지·전체 삭제 제공
필수 업무 자동 분류 카드와 짧은 수정 수집 기록을 설정한 주기로 업무 후보에 연결하고 분류·근거 표시. 이름·분류 수정과 잘못된 연결 제외 내용을 저장
필수 반복 업무 패턴화와 효율화 솔루션 한 개 실제 반복 작업의 근거와 개선 단계를 설명하고, 자동화 설계안 또는 템플릿 제시
필수 업무 회고와 일일 보고 초안 선택 기간의 업무 조회, 확인한 기록과 보완 정보로 초안 생성, 근거 열기·수정·저장·텍스트 내보내기
선택 시연 타임테이블과 프로그램 사용 집계 관측 범위 안에서 시간대별 활동과 프로그램 사용 시간을 표시하고 미수집 구간 구분
확장 세부 조건·문서 서식·지원 환경 확대 메신저 대화 상대 등 앱별 세부 필터, 주간·월간 보고와 다양한 서식, 정기 문서 생성, 고급 편집과 다양한 앱·운영체제 지원

1일 차 오전에는 시연 앱과 수집 조건을 정하고, 로컬에서 허용 여부를 판별한 뒤 최소 맥락을 수집·저장하는 기능을 구현한다. 오후에는 LLM API를 연결해 업무 자동 분류와 간단한 수정·확인을 개발한다. 2일 차에는 반복 흐름의 패턴화와 솔루션 카드, 일일 보고 초안의 근거 연결·내보내기를 구현한다. 허용·비허용 파일과 사이트를 섞어 개인정보 보호 조건도 함께 검증한다.

짧은 시연에는 실제 수집한 날짜·프로그램·범위를 표시한다. 여러 날의 누적과 다양한 직무의 활용 모습은 별도의 가상 자료로 설명한다. 메신저의 대화 상대 식별 등 앱별 세부 수집 조건은 접근성 API·연동 지원을 확인한 범위에서만 구현하고, 조건을 확인할 수 없으면 수집하지 않는다. 다양한 앱·운영체제 호환성, 하루 연속 기록과 개선안의 실제 효과는 후속 검증 대상으로 둔다.

구현 후에는 다음 순서로 시연할 계획이다.

  1. 수집 범위 선택: 업무용 프로그램과 파일명·사이트 조건을 지정하고, 제외한 개인 작업이 저장되지 않는지 보여준다.
  2. 평소처럼 작업: 기밀 없는 테스트 자료로 여러 프로그램을 오가며 자료 취합과 문서 정리를 반복한다.
  3. 업무 자동 분류: 생성된 업무 카드와 연결 근거를 확인하고, 모호한 이름·분류나 잘못된 연결만 수정한다.
  4. 효율화 솔루션 확인: 반복 작업의 패턴과 근거, 자동화할 단계와 적용 조건이 담긴 솔루션을 보여준다.
  5. 회고·문서 자동화: 같은 업무 기록을 돌아보고 일일 보고 초안을 생성·수정·내보낸다. 구현 여유가 있으면 타임테이블과 프로그램별 사용 현황도 보여준다.
04

기대효과와 검증

이 아이디어의 주요 사용자는 누구이며, 어떤 기대효과가 있나요?

주요 대상 사용자는 PC로 일하는 SDS 임직원이다. 기획·개발·분석·운영·지원 등 직무와 사용하는 도구가 달라도, 일상 업무에서 반복 수작업을 줄이고 자신의 업무를 회고하려는 필요에 대응한다. 보고서 작성 여부와 관계없이 활용할 수 있으며, 장기적으로 다양한 조직과 PC 업무 사용자에게 확장할 수 있다.

사용자의 상황 기대효과 검증 방법
자료 이동·입력·검토·서식 맞춤을 반복함 패턴화한 업무를 근거로 효율화 솔루션과 적용 방법 제안 유효한 반복 패턴, 실행 가능한 제안인지 사용자 검토. 적용 후 실제 변화 별도 확인
여러 앱에 업무 맥락이 흩어져 있음 업무 성격에 맞게 자동 연결·분류하고 누락된 일을 떠올릴 단서 제공 사용자 기준 업무와 카드의 연결·분류 정확성, 누락과 수정 부담 비교
자신의 업무 흐름을 돌아보기 어려움 기간·프로젝트·업무 유형별 회고와 개선 시도 확인 기록이 업무 이해와 다음 개선 방향 설정에 도움이 되는지 확인
일일·주간·월간 보고 등 문서를 반복 작성함 같은 업무 기록으로 문서 초안 자동 생성 수동 작성과 AI 초안 검토·보완까지의 총시간 및 사실 정확성 비교
업무·프로그램별 시간 사용이 궁금함 선택 범위의 타임테이블과 프로그램 사용 현황 제공 실제 테스트 구간과 집계 비교, 중복·유휴·미수집 구간 처리 확인
개인 작업까지 수집될까 우려함 프로그램·파일·대화·사이트 조건으로 업무 데이터 수집 범위 직접 통제 비허용 작업이 저장·분석·외부 전송에 포함되지 않는지 검증
조직에서 반복 수작업 개선 대상을 찾기 어려움 사용자가 선택해 공유한 요약으로 표준화·자동화 논의 지원 공유한 요약이 개선 우선순위 결정에 도움이 되는지 검토

해커톤에서는 분류·연결 정확성, 반복 패턴과 솔루션의 타당성, 문서 초안의 근거 품질과 전체 검토 시간을 측정한다. 최초 수집 설정과 일상적인 수정 부담도 함께 확인한다. 솔루션 제안의 유용성과 실제 적용 후의 시간 절감은 구분해 검증하며, 장기적인 업무 효율화 효과는 후속 사용을 통해 측정할 계획이다.

로그만으로 모든 업무를 관측할 수 없으므로 오프라인 업무나 미지원 앱의 작업은 필요시 사용자가 추가할 수 있게 한다. 활동량·입력 횟수·유휴 시간을 개인의 생산성 점수로 환산하지 않는다. 개인 원본 기록은 자동으로 조직에 공유하지 않고, 사용자가 선택한 업무 요약과 개선 제안만 공유할 수 있도록 설계한다.

데이터와 보호

[선택] 아이디어 구현에 필요한 데이터가 있나요?

필요한 데이터는 해커톤 중 기밀 없는 테스트 업무를 수행하며 직접 수집하거나 생성할 계획이다. 여러 날의 반복 흐름을 설명할 자료는 가상의 시연 데이터로 별도 준비한다.

구분 항목명 확보·생성 방법 / 저장 계획 데이터 포맷
수집 범위 설정 허용 프로그램·파일명 키워드·대화 상대·사이트 조건, 제외 조건 사용자가 로컬에서 설정하고 적용 가능한 앱별 범위 표시 JSON / SQLite
수집할 작업 맥락 작업 시각·사용 프로그램·문서 또는 페이지·전환 맥락 허용 조건에 맞는 최소 정보만 PC 수집 모듈에서 로컬 DB에 저장 JSON / SQLite
수집할 조작 기록 조작 종류와 입력·클릭 대상, 수집 상태 운영체제 이벤트·접근성 API와 필요한 앱 연동으로 허용 범위만 수집 JSON / SQLite
분석·사용자 확인 데이터 업무 카드·분류·근거·수정 및 확인 내역 AI 분석 결과와 사용자 수정 내용을 로컬 DB에 저장 구조화 데이터
솔루션·문서 데이터 반복 패턴·효율화 솔루션·보고 초안과 근거 연결 업무 기록과 선택적 결과·이슈·기여 보완 내용을 활용해 생성 JSON / 텍스트
부수 집계 데이터 시간대별 활동 구간·프로그램 사용 시간·업무별 시간 추정 수집한 시각·전환 맥락에서 계산하고 관측 범위·미분류 구간 함께 표시 구조화 데이터
시연·검증 자료 실제 테스트 작업과 가상의 장기 기록 기밀 없는 스프레드시트·문서·테스트 페이지와 별도 자료로 직접 준비 문서 / JSON / SQLite

개인정보 보호를 위한 선택적 데이터 수집

기본값은 수집하지 않는 상태로 두고, 사용자가 선택한 프로그램과 세부 조건에 맞는 작업만 추적하도록 설계한다. 프로그램 전체를 허용하거나, 같은 프로그램 안에서도 업무용 파일·대화·사이트로 범위를 더 좁힐 수 있게 한다.

선택 단위 사용자가 설정할 수 있는 예시 수집 제한 방식
프로그램 업무용 Excel과 문서 편집기만 선택 선택하지 않은 앱의 활동·입력 내용 제외
파일명·업무 키워드 Excel 파일명에 ‘프로젝트 A’ 또는 ‘월간집계’가 포함된 경우만 허용 같은 Excel에서도 조건 밖의 개인 파일은 제외
메신저 대화 상대·대화방 사용자가 지정한 업무 상대 또는 프로젝트 대화방만 허용 지원 앱에서 식별 가능한 대화만 대상으로 하고, 다른 대화와 전체 대화 내역은 제외
브라우저 사이트 Chrome에서 지정한 업무 도메인·경로만 허용 개인 메일·은행·개인 사이트 등 조건 밖의 탭은 제외. 전체 방문 기록·URL 쿼리는 기본 제외

허용 여부는 로컬에서 최소한의 식별 정보로 먼저 판단하고, 프로그램과 설정한 세부 조건을 함께 만족한 작업만 내용을 수집·저장한다. 제외 조건을 우선 적용하며, 조건을 판별할 수 없는 작업은 수집하지 않는다. 대상 판단에 잠시 사용한 비허용 파일명·대화 상대·사이트 정보도 기록하거나 외부로 보내지 않는다. 앱·파일·대화·탭이 전환되면 조건을 다시 확인한다. 세부 식별이 가능한지는 앱별로 검증하고 지원 범위를 표시할 계획이다.

비밀번호·인증정보 등 민감 입력, 연속 키 입력 원문, 전체 화면·클립보드 원문·문서와 대화의 전체 내용은 기본 수집 대상에서 제외한다. 기록 시작·일시중지·수집 상태 확인·전체 삭제를 제공하고, 원문은 로컬에 우선 저장하며 운영체제의 보호 기능을 활용한다. 세부 보관 기간 설정은 확장 항목으로 둔다.

수집 허용과 외부 AI 전송 허용은 별도로 설정한다. 외부 모델 분석을 사용할 때에는 허용한 자료 중 필요한 최소 맥락만 전송하고, 민감정보 가림 처리와 전송 자료 미리보기를 제공할 계획이다. 자동 분석도 사용자가 설정한 기간·자료·전송 범위 안에서만 실행한다. 원본뿐 아니라 분석 입력 사본·업무 카드·솔루션·문서 초안에도 삭제 범위를 적용한다. 이러한 설계의 실제 차단 동작은 허용·비허용 작업을 섞은 테스트로 검증한다.

필요 지원 사항: 사용할 AI 모델의 호출 권한과 접속 환경, 기밀 없는 테스트 업무를 수행할 PC와 프로그램, 다양한 직무의 업무 분류·솔루션·문서 초안을 검토할 SDS 임직원의 협조가 필요하다. 사내 자료에는 해당 환경에서 허용된 모델과 자료 범위를 적용한다.

확장과 차별점

제안해 주신 아이디어에 대해 추가로 언급하고 싶은 내용이 있으면 작성해 주세요.

WorkMemory AI를 통해 검증하고자 하는 가설은 평소처럼 일하며 쌓인 데이터를 업무 성격에 맞게 분류·패턴화하면, 반복 업무를 줄일 구체적인 솔루션을 제안하고 회고·문서 작성에도 재사용할 수 있는가다. Excel·브라우저·문서 편집기·개발 도구는 서로 다른 작업이 이어지는 활용 예시다.

집중할 지점 제공하려는 경험
