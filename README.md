# WorkMemory AI AX 해커톤

**업무를 패턴화해 효율화 솔루션을 제안하는 AI 업무 비서.**

평소처럼 일하면 사용자가 허용한 범위의 업무 데이터가 자동으로 쌓이고, AI가 업무 성격에 맞게 분류·패턴화하는 아이디어다. PC로 일하는 SDS 임직원에게 반복 수작업을 줄일 효율화 솔루션과 자동화 설계안·템플릿을 제안하고, 같은 기록으로 업무 회고와 일일·주간·월간 보고 등 문서 자동화를 돕는다.

이 저장소는 아이디어 제출을 위한 기획·설계 문서를 관리한다. 해커톤에서는 선택적 데이터 수집부터 업무 자동 분류·패턴화·효율화 솔루션 제안·업무 회고와 일일 보고 초안까지 이어지는 프로토타입을 개발할 계획이다.

## 핵심 경험

1. **수집 범위 선택:** 프로그램을 정하고 필요시 Excel 파일명 키워드, 메신저 대화 상대·대화방, Chrome 업무 사이트 등으로 범위를 좁힌다. 지원 범위 안에서 허용 조건을 수집 전에 적용한다.
2. **평소처럼 작업:** 허용한 작업의 최소 맥락이 로컬에 자동으로 쌓이고, AI가 업무 성격에 맞게 연결·분류한다. 모호한 항목만 짧게 수정한다.
3. **패턴화와 효율화 솔루션:** 반복 수작업에서 개선 대상을 찾고, 근거·개선 단계·적용 조건을 담은 자동화 설계안이나 템플릿을 제안한다.
4. **업무 회고·문서 자동화:** 기간별 업무를 돌아보고 같은 기록으로 일일·주간·월간 보고 등 필요한 문서 초안을 만든다.

부수 기능으로 업무 타임테이블, 업무별 소요 시간 추정치와 프로그램 사용 현황을 제공할 수 있다. 허용한 수집 범위·미수집 구간을 함께 표시하고, 관측 시간을 전체 근무시간이나 개인 생산성 점수로 해석하지 않는다. 수집 허용과 외부 AI 전송 허용은 별도로 설정하며, 비허용 작업은 저장·분석·전송 전에 제외하도록 설계한다.

## 해커톤 개발 계획

주요 대상 사용자는 **PC로 일하는 SDS 임직원**이다. 2일의 핵심 구현 목표는 **선택적 데이터 수집 → 업무 자동 분류·패턴화 → 효율화 솔루션 제안 → 업무 회고·일일 보고 초안 생성**이다. 다양한 도구에서 수행하는 업무를 연결하는 서비스로 설계하고, 대표 프로그램 조합을 해커톤 시연 범위로 정한다.

프로그램·파일명·사이트 조건을 로컬에서 먼저 확인한 뒤, 키보드·마우스 이벤트와 접근성 API로 필요한 조작·전환 맥락만 수집하고 로컬 DB에 저장할 계획이다. 필요하면 브라우저 확장이나 앱 연동으로 맥락을 보완한다. LLM API로 업무 자동 분류·패턴화, 효율화 솔루션과 보고 초안을 생성하고 원본 근거와 연결할 예정이다.

해커톤에서는 수집 가능성을 확인한 두 개 이상의 프로그램에서 짧은 실제 작업을 시연한다. 반복 업무 한 가지의 솔루션과 일일 보고 한 서식을 우선 구현하고, 여유가 있으면 타임테이블·프로그램 집계도 보여준다. 앱별 관측 범위와 실제·가상 자료의 출처를 구분한다. 메신저 대화 상대 등 추가 세부 필터, 주간·월간 보고와 다양한 서식, 정기 문서 생성·고급 편집·여러 앱과 운영체제 지원은 확장 항목이다. 실제 개선 효과는 솔루션 적용 후 검증한다.

**핵심 메시지:** 평소처럼 일하면 자동으로 쌓이는 업무 데이터를 AI가 업무 성격에 맞게 분류·패턴화해 업무 효율화 솔루션을 제안하고, 나의 업무 회고와 문서 자동화를 돕는 AI 업무 비서.

## Word·HTML·TXT 문서 갱신

기획서·검증 기록의 Markdown을 수정한 뒤 PowerShell 7.2 이상에서 아래 명령을 실행한다. 추가 패키지나 Word 설치 없이 HTML과 기획서 본문의 DOCX·TXT 파일을 함께 갱신한다. Word 문서는 A4, 바탕체 14포인트로 생성하며 편집 가능한 표를 유지한다. HTML은 외부 폰트·스크립트나 별도 서버 없이 열 수 있고, 텍스트 다운로드도 단독으로 동작한다. Word 다운로드 링크를 사용하려면 HTML과 DOCX를 같은 폴더에 둔다. TXT는 UTF-8 BOM과 Windows 줄바꿈으로 저장한다.

```powershell
pwsh -NoProfile -File ./scripts/export-proposal-html.ps1
```

Word 문서만 갱신하려면 `pwsh -NoProfile -File ./scripts/export-proposal-word.ps1`을 실행한다.

## GitHub Pages 배포

렌더링 페이지: **https://wookshin.github.io/AX-hackaton/**

이 공개 저장소에서 기획 문서와 Pages 배포를 함께 관리한다. 기획서·검증 기록이나 생성 스크립트를 `main`에 푸시하면 [GitHub Actions](.github/workflows/pages.yml)가 최신 Markdown을 HTML로 생성하고 Pages에 자동 배포한다. Actions 화면에서 수동으로 다시 실행할 수도 있다.

배포 대상은 생성된 `index.html`, `AX-hackathon-proposal.docx`, `AX-hackathon-proposal.txt`와 `.nojekyll`이다. 페이지에는 전체 기획서와 접을 수 있는 심사 검증 기록이 포함되며, Word·텍스트 다운로드와 GitHub 원문 링크를 제공한다. 별도 배포 저장소에 파일을 복사할 필요가 없다.

로컬에서 배포 파일을 확인하려면 새 폴더 또는 빈 폴더를 지정해 아래 명령을 실행한다.

```powershell
pwsh -NoProfile -File ./scripts/export-pages.ps1 -OutputDirectory C:\temp\workmemory-pages
```

기획서·검증 기록을 수정한 뒤 다운로드용 Word·HTML·TXT도 함께 갱신하려면 위의 `export-proposal-html.ps1`을 실행한다. 공개 페이지와 다운로드 문서는 Markdown 원문에서 자동 생성된다.
