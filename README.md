# WorkMemory AI AX 해커톤

**나의 업무를 정리하고 회고와 효율화를 돕는 AI 업무 비서입니다.**

평소처럼 일하면 사용자가 허용한 범위의 업무 데이터가 자동으로 쌓이고, AI가 어떤 일을 했는지 업무별 수행 내역으로 정리해 먼저 보여주는 아이디어입니다. 기록이 누적되어 반복 흐름이 확인되면, 비슷한 절차를 묶어 패턴화하고 수작업을 줄일 개선 방법을 제안합니다. 같은 수행 내역은 자신의 일을 돌아보는 회고와 일일·주간·월간 보고 등 필요한 문서의 초안을 작성하는 근거로 활용합니다.

이 저장소는 아이디어 제출을 위한 기획·설계 문서를 관리합니다. 해커톤에서는 선택적 데이터 수집, 업무별 수행 내역 조회, 반복 흐름의 패턴화와 개선 제안, 같은 기록을 활용한 회고·일일 보고 초안을 연결하는 프로토타입을 개발할 계획입니다.

## 핵심 경험

1. **수집 범위 선택:** 프로그램을 정하고 필요시 Excel 파일명 키워드, 메신저 대화 상대·대화방, Chrome 업무 사이트 등으로 범위를 좁힙니다. 지원 범위 안에서 허용 조건을 수집 전에 적용합니다.
2. **업무별 수행 내역 확인:** 평소처럼 일하면 허용한 작업의 정보가 사용자 PC에 쌓입니다. AI가 이를 업무 성격에 맞게 연결·분류해 업무명·수행 내용·관련 기록을 목록으로 보여줍니다. 업무 하나의 요약을 확인하는 화면을 업무 카드로 제공하며, 불확실한 항목만 짧게 수정합니다.
3. **반복 흐름에서 개선 방법 제안:** 기록이 쌓여 비슷한 목적·처리 순서가 반복되면 공통 흐름으로 묶어 패턴화합니다. 이때 수작업을 줄일 효율화 솔루션을 제안합니다. 개선 단계·조건을 정리한 자동화 설계안이나 반복 사용할 공통 양식인 템플릿을 제공합니다.
4. **같은 기록으로 회고·문서 작성:** 업무별 수행 내역이 정리된 시점부터 회고와 문서 작성에 활용합니다. 일일·주간·월간 보고, 필요시 평가 노트 등 문서 초안을 만들며, 실제 결과·기여·다음 계획은 관련 근거 또는 사용자 보완이 있을 때 반영합니다.

부수 기능으로 업무 타임테이블, 업무별 소요 시간 추정치와 프로그램 사용 현황을 제공할 수 있습니다. 허용한 수집 범위·미수집 구간을 함께 표시하고, 관측 시간을 전체 근무시간이나 개인 생산성 점수로 해석하지 않습니다. 수집 허용과 외부 AI 전송 허용은 별도로 설정하며, 비허용 작업은 저장·분석·전송 전에 제외하도록 설계합니다.

## 해커톤 개발 계획

주요 대상 사용자는 **PC로 일하는 SDS 임직원**입니다. 2일의 핵심 구현 목표는 **선택적 데이터 수집 → 업무별 수행 내역 정리·조회 → 반복 흐름의 패턴화와 개선 제안 → 같은 기록의 회고·일일 보고 활용**입니다. 다양한 도구에서 수행하는 업무를 연결하는 서비스로 설계하고, 대표 프로그램 조합을 해커톤 시연 범위로 정합니다.

프로그램·파일명·사이트 조건을 사용자 PC에서 먼저 확인한 뒤, 허용한 작업의 조작·전환 정보만 수집해 저장할 계획입니다. 필요한 경우 앱 연동으로 정보를 보완합니다. AI 모델은 업무별 수행 내역을 정리하고, 누적된 기록의 반복 흐름을 분석해 개선 방법을 제안합니다. 문서 초안은 정리된 수행 내역과 사용자가 보완한 정보를 근거로 생성합니다. 세부 기술은 설계 메모에서 설명합니다.

해커톤에서는 수집 가능성을 확인한 두 개 이상의 프로그램에서 짧은 실제 작업을 시연합니다. 업무별 수행 내역을 먼저 보여주고, 반복 업무 한 가지의 개선 제안과 일일 보고 한 서식을 구현합니다. 여유가 있으면 타임테이블·프로그램 집계도 보여줍니다. 앱별 관측 범위와 실제·가상 자료의 출처를 구분합니다. 메신저 대화 상대 등 추가 세부 필터, 주간·월간 보고와 다양한 서식, 정기 문서 생성·고급 편집·여러 앱과 운영체제 지원은 확장 항목입니다. 실제 개선 효과는 솔루션 적용 후 검증합니다.

**핵심 메시지:** 평소처럼 일하면 AI가 업무별 수행 내역을 정리해 보여주고, 누적 기록에서 확인된 반복 흐름을 패턴화해 효율화 솔루션을 제안하며 같은 기록으로 업무 회고와 문서 자동화를 돕는 AI 업무 비서입니다.

## Word·HTML·TXT 문서 갱신

기획서·검증 기록의 Markdown을 수정한 뒤 PowerShell 7.2 이상에서 아래 명령을 실행합니다. 추가 패키지나 Word 설치 없이 HTML과 기획서 본문의 DOCX·TXT 파일을 함께 갱신합니다. Word·TXT는 웹용 도입 요약을 제외하고 제목과 공식 질문 1~7번·안내 문구·답변으로 구성합니다. 6번 데이터 표는 ‘구분’, ‘항목명’, ‘현재 위치 / 시스템’, ‘데이터 포맷’의 4개 열로 구성합니다. Word 문서는 A4, 바탕체 14포인트로 생성하며 편집 가능한 표를 유지합니다. HTML은 외부 폰트·스크립트나 별도 서버 없이 열 수 있고, 텍스트 다운로드도 단독으로 동작합니다. Word 다운로드 링크를 사용하려면 HTML과 DOCX를 같은 폴더에 둡니다. TXT는 UTF-8 BOM과 Windows 줄바꿈으로 저장합니다.

```powershell
pwsh -NoProfile -File ./scripts/export-proposal-html.ps1
```

Word 문서만 갱신하려면 `pwsh -NoProfile -File ./scripts/export-proposal-word.ps1`을 실행합니다.

## GitHub Pages 배포

렌더링 페이지: **https://wookshin.github.io/AX-hackaton/**

이 공개 저장소에서 기획 문서와 Pages 배포를 함께 관리합니다. 기획서·검증 기록이나 생성 스크립트를 `main`에 푸시하면 [GitHub Actions](.github/workflows/pages.yml)가 최신 Markdown을 HTML로 생성하고 Pages에 자동 배포합니다. Actions 화면에서 수동으로 다시 실행할 수도 있습니다.

배포 대상은 생성된 `index.html`, `AX-hackathon-proposal.docx`, `AX-hackathon-proposal.txt`와 `.nojekyll`입니다. 페이지에는 전체 기획서와 접을 수 있는 심사 검증 기록이 포함되며, Word·텍스트 다운로드와 GitHub 원문 링크를 제공합니다. 별도 배포 저장소에 파일을 복사할 필요가 없습니다.

로컬에서 배포 파일을 확인하려면 새 폴더 또는 빈 폴더를 지정해 아래 명령을 실행합니다.

```powershell
pwsh -NoProfile -File ./scripts/export-pages.ps1 -OutputDirectory C:\temp\workmemory-pages
```

기획서·검증 기록을 수정한 뒤 다운로드용 Word·HTML·TXT도 함께 갱신하려면 위의 `export-proposal-html.ps1`을 실행합니다. 공개 페이지와 다운로드 문서는 Markdown 원문에서 자동 생성됩니다.
