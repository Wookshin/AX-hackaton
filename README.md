# WorkMemory AI AX 해커톤

**나도 몰랐던 나의 일을 찾아주는 AI 업무 기억 비서.**

평소 작업에서 쌓이는 입력·클릭과 프로그램 활동을 AI가 업무로 연결한다. 빠뜨린 일을 복원하고, 개별 행동으로 여겼던 기록에서 반복해서 맡고 있던 업무를 발견한다. 확인한 업무를 주간·월간 보고에 재사용하는 AX 해커톤 기획 저장소다.

기반 프로젝트는 [WorkMemory AI](https://github.com/Wookshin/WorkMemoryAI)이며, 로컬에서는 상위 폴더의 `work-memory`에 있다. 이 저장소에는 기획·설계 문서를 관리한다.

## 문서

- [웹에서 바로 보는 기획서](https://wookshin.github.io/AX-hackaton/): GitHub Pages에 배포한 렌더링 페이지.
- [읽기 편한 HTML 기획서](AX-hackathon-proposal.html): 목차·핵심 요약·전체 기획서와 접을 수 있는 심사 검증 기록. 파일을 내려받아 브라우저에서 열면 되며 모바일 보기, 텍스트 다운로드와 인쇄·PDF 저장을 지원한다.
- [Word 복사용 텍스트 기획서](AX-hackathon-proposal.txt): 기획서 본문 7개 항목을 담은 순수 텍스트. 마크다운 서식을 제거하고 표를 항목명과 내용으로 풀어 썼다. 메모장에서 열어 전체 선택(Ctrl+A)·복사(Ctrl+C) 후 Word 제출 양식에 붙여 넣으면 된다. HTML 상단의 ‘텍스트 다운로드’ 버튼으로도 같은 파일을 받을 수 있다.
- [제출용 기획서](AX-hackathon-proposal.md): 해커톤 제출 양식의 7개 항목에 맞춘 문제·AI 활용·2일 구현 범위·기대효과·데이터 계획.
- [제품·AI 설계 메모](AX-hackathon-implementation-notes.md): 기존 구현 범위, 업무 복원 흐름, 데이터 구조, 모델 연결과 검증 방법.
- [심사기준 기반 검증 기록](AX-hackathon-review.md): 독립 검증 에이전트 3개의 검토 결과, 평가항목별 보완 내용과 남은 검증 과제.

## 핵심 경험

1. **평소처럼 작업:** 사용자가 기록을 시작하면 수집 가능한 앱과 사이트의 활동을 로컬에 저장한다.
2. **오늘의 업무 복원:** AI가 업무 후보 목록을 보여주고, 사용자는 필요한 부분만 수정한 뒤 선택한 카드 묶음을 확인한다.
3. **놓친 업무와 반복 흐름 발견:** 빠뜨린 일을 확인하고, 흩어진 조회·안내 기록에서 반복 지원업무와 개선 후보를 찾는다.
4. **기간별 보고 작성:** 확인한 업무를 일간·주간·월간 보고로 정리하고, 근거 확인·수정·내보내기를 제공한다.

## 현재 기반과 추가 구현

첫 사용자는 조회·문의 응답 작성과 주간보고를 반복하는 사내 시스템 운영·지원 담당자다. 2일의 필수 완주 범위는 **짧은 실제 로그 → 업무 카드 → 간단한 확인 → 근거가 연결된 주간보고**다. 누적 반복 인사이트·월간 확장·고급 편집은 선택 구현으로 구분한다.

`work-memory`에는 Windows 프로그램 활동 구간, Chrome·Windows 앱의 입력값 변경·클릭 수집, 로컬 저장과 원본 조회가 구현되어 있다. 앱별 수집 범위에 차이가 있으며 창 제목·전체 화면·전체 페이지 내용은 수집하지 않는다.

업무 카드, AI 분석, 사용자 확인·수정, 반복 업무 제안과 기간별 보고는 이번 기획의 추가 구현 대상이다. 문서의 기존 구현 상태는 소스·문서 확인 기준이며 이번 기획 작업에서 앱 실행이나 모델 연결을 검증한 결과는 아니다. 장기 분석 시연을 위한 가상 기록은 실제 수집 결과와 구분한다.

**핵심 메시지:** 평소처럼 일하면, AI가 빠뜨린 일과 반복해서 맡고 있던 업무를 찾아내고 보고와 개선의 단서로 정리한다.

## HTML 문서 갱신

기획서·검증 기록의 Markdown을 수정한 뒤 PowerShell 7.2 이상에서 아래 명령을 실행한다. 추가 패키지 설치 없이 두 원문을 하나의 HTML로 다시 생성하고, 기획서 본문의 TXT 파일도 함께 갱신한다. HTML은 외부 폰트·스크립트나 별도 서버 없이 열 수 있고, 텍스트 다운로드도 단독으로 동작한다. TXT는 한글 호환을 위해 UTF-8 BOM과 Windows 줄바꿈으로 저장한다.

```powershell
pwsh -NoProfile -File ./scripts/export-proposal-html.ps1
```

## GitHub Pages 배포

렌더링 페이지: **https://wookshin.github.io/AX-hackaton/**

이 공개 저장소에서 기획 문서와 Pages 배포를 함께 관리한다. 기획서·검증 기록이나 생성 스크립트를 `main`에 푸시하면 [GitHub Actions](.github/workflows/pages.yml)가 최신 Markdown을 HTML로 생성하고 Pages에 자동 배포한다. Actions 화면에서 수동으로 다시 실행할 수도 있다.

배포 대상은 생성된 `index.html`, `AX-hackathon-proposal.txt`와 `.nojekyll`이다. 페이지에는 전체 기획서와 접을 수 있는 심사 검증 기록이 포함되며, 원문 링크는 이 저장소의 GitHub 파일로 연결된다. 별도 배포 저장소에 파일을 복사할 필요가 없다.

로컬에서 배포 파일을 확인하려면 새 폴더 또는 빈 폴더를 지정해 아래 명령을 실행한다.

```powershell
pwsh -NoProfile -File ./scripts/export-pages.ps1 -OutputDirectory C:\temp\workmemory-pages
```

기획서·검증 기록을 수정한 뒤 다운로드용 HTML도 함께 갱신하려면 위의 `export-proposal-html.ps1`을 실행한다. 공개 페이지는 Markdown 원문에서 자동 생성된다.
