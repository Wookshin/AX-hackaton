# Mori AX 해커톤

**평소처럼 할 일을 기록하면, AI가 개선점을 먼저 찾고 나의 회고와 팀의 협업으로 연결해 주는 ToDo.**

기존 [Mori ToDo](https://github.com/Wookshin/mori-todo)를 기반으로 개인과 팀의 업무 개선 경험을 제안하는 AX 해커톤 기획 저장소입니다.

## 문서

- [제출용 기획서](AX-hackathon-proposal.md): 해커톤 제출 양식의 7개 항목에 맞춘 제안입니다.
- [제품·AI 설계 메모](AX-hackathon-implementation-notes.md): 사용자 경험, 카테고리 공유, AI 분석, 데이터 구조와 검증 방법을 정리했습니다.

## 주요 아이디어

- **개인 개선 제안:** 쌓인 ToDo에서 반복 업무와 개선 후보를 AI가 먼저 발견합니다.
- **숨은 협업 발견:** 팀에 공유한 카테고리에서 중복·재사용·협업 기회를 찾습니다.
- **팀 ToDo 리뷰:** 공유 업무를 돌아보고 개선 과제를 실행한 뒤 다음 리뷰에서 확인합니다.
- **개인 주간 회고:** 한 주의 기록과 연간 목표를 연결해 일기와 다음 행동으로 남깁니다.
- **보고·평가노트:** 공개 범위와 목적에 맞게 업무 기록을 정리하고 원본 근거를 확인합니다.

개인 카테고리와 개인 일기는 팀 분석에서 제외합니다. 상세한 시행착오나 노하우 메모를 필수로 작성하지 않아도 평소의 업무 기록으로 분석을 시작하는 방향입니다.
