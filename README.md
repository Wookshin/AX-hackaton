# WorkMemory AI AX 해커톤

**나도 몰랐던 나의 일을 찾아주는 AI 업무 기억 비서.**

PC의 키보드·마우스 조작과 작업 맥락을 AI가 업무로 연결하고, 나의 일을 기억·분류하며 반복 작업의 개선 기회를 찾도록 돕는 아이디어다. PC로 일하는 SDS 임직원을 대상으로 확인한 업무를 평가노트용 사례로 축적하고, 필요한 경우 주간·월간 보고에도 재사용하는 서비스를 제안한다.

이 저장소는 아이디어 제출을 위한 기획·설계 문서를 관리한다. 해커톤에서는 PC 조작·맥락 수집부터 업무 복원·분류·반복 패턴 발견·평가노트용 사례 정리까지 이어지는 프로토타입을 개발할 계획이다.

- [제품·AI 설계 메모](AX-hackathon-implementation-notes.md): 활용할 기술과 개발 범위, 업무 복원 흐름, 데이터 구조, 모델 연결과 검증 계획.

## 핵심 경험

1. **평소처럼 작업:** Excel·브라우저·문서 편집기·개발 도구 등을 오가는 PC 조작과 맥락을 로컬에 기록한다.
2. **업무 복원·분류:** AI가 관련 기록을 업무 목적에 따라 연결하고 분류한다. 사용자는 이름·분류·잘못된 연결을 짧게 수정하고 확인한다.
3. **반복 작업 개선:** 자료 이동·입력·정리의 반복에서 표준화·자동화 등을 검토할 인사이트와 근거를 찾는다.
4. **평가노트에 활용:** 확인한 업무에 실제 결과·기여를 보완해 평가노트용 사례를 축적한다. 필요한 직무에서는 같은 기록을 주간·월간 보고에도 활용한다.

## 해커톤 개발 계획

주요 대상 사용자는 **PC로 일하며 평가노트를 작성하는 SDS 임직원**이다. 2일의 핵심 구현 목표는 **PC 작업 기록 수집 → 업무 복원·분류 → 반복 흐름 발견 → 평가노트용 사례 정리**다. 다양한 도구에서 수행하는 업무를 연결하는 서비스로 설계하고, 대표 프로그램 조합을 해커톤 시연 범위로 정한다.

키보드·마우스 이벤트와 접근성 API로 조작·앱·문서 전환 맥락을 수집하고 로컬 DB에 저장하는 방안을 계획한다. 필요하면 브라우저 확장이나 앱 연동으로 맥락을 보완한다. LLM API로 업무 연결·분류, 반복 패턴·개선 후보, 평가노트용 사례를 생성하고 원본 근거와 연결할 예정이다.

해커톤에서는 수집 가능성을 확인한 두 개 이상의 프로그램에서 짧은 실제 작업을 시연한다. 앱별 관측 범위와 실제·가상 자료의 출처를 구분하고, 다양한 앱·운영체제 지원과 평가기간 전체의 활용 효과는 후속 검증 대상으로 둔다. 주간·월간 보고, 평가노트 전체 서식과 고급 편집은 확장 항목이다.

**핵심 메시지:** PC에서 평소처럼 일하면, AI가 나의 업무를 기억·분류하고 평가노트에 활용할 근거와 반복 작업을 개선할 인사이트를 제공한다.

## Word·HTML·TXT 문서 갱신

기획서·검증 기록의 Markdown을 수정한 뒤 PowerShell 7.2 이상에서 아래 명령을 실행한다. 추가 패키지나 Word 설치 없이 HTML과 기획서 본문의 DOCX·TXT 파일을 함께 갱신한다. Word 문서는 A4, 바탕체 14포인트로 생성하며 편집 가능한 표를 유지한다. HTML은 외부 폰트·스크립트나 별도 서버 없이 열 수 있고, 텍스트 다운로드도 단독으로 동작한다. Word 다운로드 링크를 사용하려면 HTML과 DOCX를 같은 폴더에 둔다. TXT는 UTF-8 BOM과 Windows 줄바꿈으로 저장한다.

```powershell
pwsh -NoProfile -File ./scripts/export-proposal-html.ps1
```

Word 문서만 갱신하려면 `pwsh -NoProfile -File ./scripts/export-proposal-word.ps1`을 실행한다.

## GitHub Pages 배포

렌더링 페이지: **https://wookshin.github.io/AX-hackaton/**

이 공개 저장소에서 기획 문서와 Pages 배포를 함께 관리한다. 기획서·검증 기록이나 생성 스크립트를 `main`에 푸시하면 [GitHub Actions](.github/workflows/pages.yml)가 최신 Markdown을 HTML로 생성하고 Pages에 자동 배포한다. Actions 화면에서 수동으로 다시 실행할 수도 있다.

배포 대상은 생성된 `index.html`, `AX-hackathon-proposal.docx`, `AX-hackathon-proposal.txt`와 `.nojekyll`이다. 페이지에는 전체 기획서와 접을 수 있는 심사 검증 기록이 포함되며, Word·텍스트 다운로드와 GitHub 원문 링크를 제공한다. 별도 배포 저장소에 파일을 복사할 필요가 없다.

로컬에서 배포 파일을 확인하려면 새 폴더 또는 빈 폴더를 지정해 아래 명령을 실행한다.

```powershell
pwsh -NoProfile -File ./scripts/export-pages.ps1 -OutputDirectory C:\temp\workmemory-pages
```

기획서·검증 기록을 수정한 뒤 다운로드용 Word·HTML·TXT도 함께 갱신하려면 위의 `export-proposal-html.ps1`을 실행한다. 공개 페이지와 다운로드 문서는 Markdown 원문에서 자동 생성된다.
